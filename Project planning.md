Project Planning
1. Introduction

Project Planning is the process of defining project objectives, activities, resources, and timelines required to complete the project successfully. This project focuses on automating standard laptop procurement using ServiceNow Flow Designer to reduce manual work and improve efficiency.

2. Project Objectives
Automate standard laptop procurement.
Create catalog tasks automatically after approval.
Assign configuration tasks to the Hardware team.
Reduce manual intervention and processing delays.
Improve IT resource utilization.
Enhance user satisfaction.
3. Project Scope

The project covers the automation of standard laptop requests through ServiceNow Service Catalog and Flow Designer. It includes request submission, approval, automatic catalog task creation, task description updates, and assignment to the Hardware group.

4. Project Phases
Phase 1: Requirement Gathering
Identify problems in the existing procurement process.
Understand the need for workflow automation.
Define functional and non-functional requirements.
Identify required ServiceNow modules.
Phase 2: System Design
Design the automated workflow.
Identify the Service Catalog trigger.
Define the Catalog Task creation process.
Plan automatic assignment to the Hardware group.
Phase 3: Flow Development
Open ServiceNow Flow Designer.
Create a new flow named Standard Laptop Task.
Configure the application as Global.
Set Run As to System User.
Select the Service Catalog trigger.
Add the Create Catalog Task action.
Configure the required fields.
Phase 4: Flow Assignment
Open Maintain Items.
Search for the Standard Laptop catalog item.
Navigate to Process Engine.
Remove the existing automation configuration where applicable.
Assign the newly created flow.
Save the configuration.
Phase 5: Testing
Submit a Standard Laptop request.
Verify the approval process.
Approve the request.
Check whether the catalog task is generated.
Verify the short description and assignment group.
Confirm the workflow execution.
Phase 6: Implementation
Activate the flow.
Integrate it with the Standard Laptop catalog item.
Execute the automated procurement workflow.
Monitor task creation and assignment.
